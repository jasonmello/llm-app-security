# Contributing

- Keep it defensive. Contributions that add offensive tooling, instructions
  aimed at manipulating other agents, or active countermeasures will be declined.
- New pitfalls: add them to `02-LLM-CODE-PITFALLS.md` with how to detect and fix,
  and, if possible, a planted example in `examples/vulnerable-vibe-app` plus a
  row in `examples/ANSWER_KEY.md`.
- Run `npm test` before opening a PR. No runtime dependencies, please.
