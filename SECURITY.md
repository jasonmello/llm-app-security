# Security policy

## Reporting

If you find a problem in this skill that could cause an agent to act unsafely
(for example, instructions that lead it to leak secrets, run untrusted code or
follow injected text), or a bug in the scripts or templates with security
impact, please report it privately through
[GitHub private vulnerability reporting](https://github.com/jasonmello/llm-app-security/security/advisories/new)
(Security → Report a vulnerability) instead of opening a public issue.

## Scope

The skill text (`skills/jason/*.md`), its scripts and templates.
The example app in `examples/` is insecure on purpose; its planted flaws are
not vulnerabilities.

## Supported versions

Only the latest release is supported. This is a volunteer project: expect a
first response within about a week.
